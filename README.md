Lulusan S1 Pendidikan Teknik Informatika dari Universitas Negeri Padang yang memadukan keahlian pengembangan perangkat lunak dengan kompetensi desain visual. Memiliki rekam jejak merancang aplikasi berbasis web (Laravel) dan analysis data (Python), sekaligus berpengalaman secara profesional mengeksekusi aset visual strategis utuk instansi pemerintahan (Kanwil Kemenkum Sumatera Barat). Terbiasa menjembatani kebutuhan teknis programming dengan komunikasi visual, sehingga kebutuhan mampu menghasilkan produk digital yang tidak hanya fungsional secara sistem, tetapi juga estetis dan user-friendly.
